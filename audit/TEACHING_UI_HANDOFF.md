## Behaviour decisions (please check)
- Phases: introduce, demonstrate (Back/Next, also back into introduce), guided, practice (sorted easy to hard by `difficulty`), check, result, remediation (explain, guided, alternate check, result) up to `max_remediation_cycles`, then needs support.
- Guided and remediation-guided: 'Hint' button reveals hints[] one at a time; wrong tap shows wrong_feedback, option greyed, retry free, no penalty; 'Well done' + explanation after the right answer; Next only after solved. Practice: same feedback, NO hint button, explanation only after solved. Check: pick then Next, no colours/feedback/hints; result page shows score and a per-item review (this is where explanations first appear).
- Pass = score >= check_pass (or remediation_pass). Pass calls `recordResult(correct:true)` once, only if the lesson is not already in completedLessons (replays pay nothing and are not counted). Needs support: status saved, NOT completed, no stars; screen offers 'Back to the map' and 'Try again from the start'.
- Remediation cycle 2 reuses the same remediation items (the plan has only one set) in rotated order and with a different option shuffle.
- Option order: seeded shuffle; the right answer is never left in its stored slot and not in the same slot as the previous question (3+ options).
- Audio-only items (visual none): one large 'Listen again' tile (`replay_button`) replaces the small Listen button. If the device voice is missing an inline notice says to ask a grown-up (it does not print the spoken answer, so for check items whose answer is only spoken a grown-up is needed; there is no text fallback by design).
- optionPictures: shown whenever present, left of the option text, 72dp.
- Picture visuals with empty caption print nothing; a placeholder for a question picture says only 'Artwork coming soon' (no concept label).
- Resume: the phase is saved when each phase begins; reopening starts at the beginning of that phase (remediation resumes at the explain step of the saved cycle). Mastered lessons always replay from the start.
- Progress stored in `ProgressRecord.teaching[lessonId]`; key `teaching` is written only when non-empty, so old saves round-trip byte-for-byte in that respect.
- Chrome text (Listen, Hint, Next, Back, scores) is English everywhere, like the existing screens; the pass dialog is the existing LessonResultDialog in the lesson language.
- Result strings 'Well done!', 'Let's look at it another way.' etc. are mine, not from the plan.
